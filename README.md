# 🍃 Course MongoDB Project

> API REST desenvolvida em **Java** utilizando **Spring Boot** e **MongoDB**, aplicando conceitos de bancos de dados NoSQL, modelagem de documentos e persistência de dados.

Este projeto foi desenvolvido para aprofundar os conhecimentos em desenvolvimento Backend com o ecossistema Spring, explorando as principais diferenças entre bancos relacionais e NoSQL através da construção de uma API REST utilizando MongoDB.

---

# ▶️ Como executar

Clone o projeto

```bash
git clone https://github.com/ErikOliveiraa/course-mongo-project.git
```

Execute

```bash
mvn spring-boot:run
```

A API ficará disponível em:

```
http://localhost:8080
```
